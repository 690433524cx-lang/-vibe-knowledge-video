# 《兽格觉醒》系列规范

16 型人格 × 16 种动物。**每做一期之前先读完这个文件，并严格遵守。** 规范与实现冲突时，以规范为准，改实现。

核心目标：**帅到让人一看就喊出来“这是我的动物”**，像游戏里抽到稀有角色的那一刻。威风、帅气，不可爱、不卡通。

---

## 1. 画面

| 项目 | 规定 |
|---|---|
| 尺寸 | 横屏 1920×1080 |
| 帧率 | 30 fps |
| 时长 | 合集约 45 秒；单集约 20 秒；觉醒出场约 3 秒 |
| 封面 / 收藏卡 | 竖版 4:5，1080×1350，由同一套引擎渲染 |

## 2. 颜色

按 MBTI 四大类，每类一个主色。同一类的四只动物共用主色，靠动物造型和专属特效区分。

| 类别 | 类型 | 主色 |
|---|---|---|
| NT 分析家 | INTJ INTP ENTJ ENTP | 紫 `#A24BFF` |
| NF 外交家 | INFJ INFP ENFJ ENFP | 绿 `#2BE36B` |
| SJ 守护者 | ISTJ ISFJ ESTJ ESFJ | 蓝 `#3AA8FF` |
| SP 探险家 | ISTP ISFP ESTP ESFP | 黄 `#FFC23D` |

- 背景近黑（`#05050A` 左右），带细小星点，动物身后有一团**轻微**的主色光晕。
- **不要铺满全屏的雾。** 雾、光晕只在动物身后和画面边缘，中心区域保持干净。
- 粒子本身：受光面偏白（主色混白），背光面和轮廓用主色。

## 3. 动物

- 全部由**发光粒子**组成，形状来自 3D 模型（模型来源、授权写进 `CREDITS.md`）。
- 模型 → 粒子：在表面采样 **20 万个以上**的点；按光照决定疏密和亮度（顶光 + 轮廓光：受光处密且亮，背光处稀且暗），轮廓边缘最亮。
- **眼睛是全画面最亮的两个点**，单独加两个发光点，不随表面采样。
- 粒子始终有轻微闪烁和流动；毛发 / 羽毛的粒子可以被风吹动。
- 姿态：头部和上半身为主，正面或 3/4 侧面，低机位略微仰视。神情威风、帅气。
- 缩到手机宽度（400px）也必须一眼认出是什么动物：耳朵、口鼻、头型这些轮廓特征优先保证清楚。

## 4. 字体与字号

| 用途 | 字体 | 字号 |
|---|---|---|
| 中文标题、称号 | 思源宋体 Heavy（Noto Serif CJK SC Black），次级用 Bold | 大标题 ≥ 150px |
| MBTI 字母 | 粗衬线大写（Cinzel 900，`assets/fonts/Cinzel.ttf`） | 与大标题同级 |
| 字幕 | 思源宋体 Bold | 52px |
| 标签、天赋词 | 思源宋体 Bold | 44px |
| 左上角 logo | 思源宋体 Heavy | 34px |

- 标题用金属渐变 + 主色发光；文字离画面边缘至少 60px。
- **文字不能压到动物的眼睛和脸**（引擎每帧记录文字框和脸框，`qa.js` 检查）。

## 5. 片头

- 不超过 1.5 秒。
- **第 0 帧必须已经有画面**：黑暗中发光的两只眼睛。
- 左上角常驻小 logo“兽格觉醒”，全片不消失。

## 6. 结尾

- 16 只动物排成 4×4 的墙。
- **最后一帧和第 0 帧一样**，可以无缝循环（所有周期运动的频率按成片时长量化）。

## 7. 觉醒出场（每只动物都用，约 3 秒，卡在音乐上）

以“觉醒时刻” H（= 某小节第一拍）为基准，其余时间都相对 H。实际实现按拍子取整：眼睛从 H 前 3 拍左右开始（90 BPM 时正好 2.0 秒），汇聚从 H 前 2 拍开始，天赋词落在 H 后的三个十六分音符上：

| 时间 | 画面 |
|---|---|
| H−2.0 → H−1.5 | 黑暗中只有两点光（眼睛），其他什么都没有 |
| H−1.5 → H | 四面八方的粒子沿旋涡路径被吸过去，从眼睛开始向外拼出头、身体；带拖尾，越来越快 |
| **H** | 觉醒：眼睛猛地燃起（冲到最亮再回落）；身后炸开一圈主色能量光环；地面扫过一道冲击波；镜头轻微震动；粒子向外弹一下再收回。**不能整屏闪白**，最亮的只有眼睛和光环 |
| H → H+1.0 | 英雄定格：低机位略仰视、3/4 侧面、镜头缓慢推近；毛发 / 羽毛粒子像被风吹动向后飘；打出称号大字“类型 · 称号”，下面三个天赋词按拍点依次弹出 |

觉醒之后，每只动物的**专属能量特效**一直存在，跟着音乐律动（见 `episode.json` 的 `fx`）。

## 8. 质量标准（每次出片前都要自查，`qa.js` 自动检查）

1. 每帧亮度高于 240 的像素 **不超过 0.5%**。
2. 任何 0.5 秒内画面都有明显变化（不出现死帧）。
3. 文字不能压到动物的眼睛和脸。
4. 首尾帧一致（合集、单集；觉醒片段除外）。
5. 所有画面事件对齐音乐拍点，误差 **< 0.04 秒**（`sync_check.js`）。
6. 缩小到手机尺寸（宽 400px）也能一眼认出动物；整体是“威风、帅气”，不是“可爱、卡通”。

## 9. 配置驱动

每一期都由一个 `episode.json` 生成，封面 / 收藏卡也由同一套引擎、同一个配置渲染。字段：

```jsonc
{
  "id": "wolf",                    // 文件名与资源名
  "type": "INFJ",                  // MBTI 类型
  "group": "NF",                   // NT / NF / SJ / SP → 决定主色
  "color": "#2BE36B",              // 主色（必须等于该类主色）
  "animal": { "zh": "狼", "en": "Wolf", "model": "wolf" },   // model = assets/models/<model>.json
  "title": "月下孤狼",              // 称号
  "talents": ["洞察", "共情", "坚守"],
  "quote": "……",                    // 收藏卡上的一句话
  "facts": ["……"],                  // 冷知识（单集用）
  "fx": "moon",                     // 专属特效：moon / startrail / foxfire / shadow …
  "pose": { … },                    // 模型姿势（骨骼额外旋转）
  "camera": { … },                  // 英雄镜头：目标、方位角、仰角、距离
  "music": { "file": "…", "hit": 0 } // 觉醒时刻对准的小节第一拍（秒）
}
```

## 10. 目录

```
videos/beast/
  SERIES.md            本文件
  CREDITS.md           模型、字体、音乐的来源与授权
  episodes/<id>.json   每只动物一份配置
  assets/models/       姿势固定后的网格（由 tools/gltf_to_mesh.js 生成）
  assets/fonts/        Cinzel（OFL）
  src/                 引擎：粒子、特效、文字、收藏卡
  beats.json           音乐节拍（tools/beats.py 生成）
  index.html           渲染页面（?ep=wolf&mode=video|still|card）
  stills.js render.js  截图与出片
  qa.js                质量检查
```
