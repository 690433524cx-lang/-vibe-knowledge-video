# 《兽格觉醒》系列规范

16 型人格 × 16 种动物。**每做一期之前先读完这个文件，并严格遵守。** 规范与实现冲突时，以规范为准，改实现。
本版以“狼（INFJ）觉醒段完整修改要求”为准，作为 16 只动物的统一规范；之前关于狼的零散修改一律作废。

核心目标：**帅到让人一看就喊出来“这是我的动物”**，像游戏里抽到稀有角色的那一刻。威风、帅气，不可爱、不卡通。

---

## 1. 画面与音乐

| 项目 | 规定 |
|---|---|
| 尺寸 | 横屏 1920×1080，30 fps |
| 单集 | 约 26–27 秒：开头 + 觉醒（约 7 秒）+ 正文（约 14–15 秒）+ 结尾（约 4 秒），按实测节拍取整；音乐不重复，在歌曲结束前收尾，最后 0.6 秒淡出；首尾无缝循环 |
| 合集 | 约 45 秒（16 只） |
| 收藏卡 / 封面 | 竖版 4:5，1080×1350，同一套引擎、同一个配置渲染 |
| 单集音乐 | `音乐_MBTI_原版.mp4`（29 秒原曲）。**必须从歌曲的第一个音开始，不能从中间截取** |
| 合集音乐 | 45 秒的 `音乐_MBTI.mp4`，只给 16 只合集用 |

- 节拍一律实测（`tools/beats.py` → `beats.json`），不估。原曲 90 BPM；片头说的“每一拍”是八分音符（约 0.333 秒）。
- **T_REVEAL** = 歌曲**第 4 个小节的第一拍**（按“一拍 ≈ 0.333 秒、4 拍一小节”计；原曲实测起音 4.000 秒，网格 3.996 秒，第 120 帧）：主角卡翻面亮相。
- **T_AWAKE** = T_REVEAL 之后的下一个小节第一拍（5.329 秒，第 160 帧；低音鼓进来、乐句开头）：每只动物都在 T_AWAKE 觉醒，叫声加在这一拍。

### 1.1 叫声与音乐让位

- 叫声用**真实录音**，CC0 或可商用授权，2–4 秒、有回声、有气势；**绝不用代码合成**。来源和授权写进 `CREDITS.md`。
- 找到录音：叫声从 T_AWAKE 开始，音量明显盖过音乐；背景音乐在 T_AWAKE 后 **0.1 秒内降到 30%**，保持到叫声结束，再用 **0.8 秒**恢复。交付“有叫声”和“无叫声”两版。
- 找不到合格录音：只做音乐降到 30% 的处理（默认保持 2.0 秒），叫声由剪辑时在剪映里加。
- 交付时写明 **T_AWAKE 在视频里的准确时间（精确到 0.01 秒）和帧号**。

## 2. 颜色

按 MBTI 四大类，每类一个主色。

| 类别 | 类型 | 主色 |
|---|---|---|
| NT 分析家 | INTJ INTP ENTJ ENTP | 紫 `#A24BFF` |
| NF 外交家 | INFJ INFP ENFJ ENFP | 绿 `#2BE36B` |
| SJ 守护者 | ISTJ ISFJ ESTJ ESFJ | 蓝 `#3AA8FF` |
| SP 探险家 | ISTP ISFP ESTP ESFP | 黄 `#FFC23D` |

- 画面以这一类的主色为主；背景近黑（`#05050A` 左右）带细小星点，**不要整屏一片暗色调的主色，也不要铺满全屏的雾**。
- 月亮 / 主光源用偏白的主色淡色（狼：偏白的淡绿）。

## 3. 动物

- 全部由**发光粒子**组成，形状来自 3D 模型（来源、授权写进 `CREDITS.md`）。在表面采样 **20 万个以上**的点；受光处密且亮，背光处稀且暗，轮廓边缘最亮。
- **眼睛是全画面最亮的两个点**，单独加两个发光点。
- 动物要像**真正的这种动物**，不能像别的动物（狼不能像狗）：抓住这种动物最有辨识度的造型（狼：长而粗的吻部、直鼻梁、竖立向前的耳朵、又厚又蓬的颈毛、高肩、粗壮的四肢）。造型用模型参数（`dump_animal.js` 的 overrides、warps）和姿势工具（`pose_animal.js`：四肢加粗、颈毛加长加密、骨骼姿势）调整，**不改模型库**。
- 身体不能大部分隐没在黑暗里：主光（月光）从背后打出亮边，再加一点正面补光，看得清肌肉和毛发的走向。
- 动物前面有大的发光背景（月亮）时，用动物自己的网格画一层暗色遮罩（同样的骨骼动作），形成清楚的剪影，粒子亮边画在剪影上。
- 粒子始终有轻微闪烁和流动；毛发 / 羽毛的粒子像被风吹动。
- 缩到手机宽度（400px）第一眼必须认出是什么动物。

## 4. 文案规则（16 只全部适用）

1. **不要任何四字称号**（例如“月下孤狼”），**不要天赋词**。
2. 画面大字只写“**类型 · 动物名**”，例如“INFJ · 狼”（类型字母 Cinzel 900，动物名思源宋体 Heavy，≥150px，金属渐变 + 主色发光）。
3. 大字下方是**一句话**：52px，白色，关键词用这一类的颜色，带暗色底。

| 类型 · 动物 | 一句话（〔〕内为关键词） |
|---|---|
| INFJ · 狼 | 你很少开口，但总能〔看穿人心〕。 |
| INTP · 猫头鹰 | 你不是在发呆，是〔想得更深〕。 |
| ENTP · 狐狸 | 别人只看到两条路，你总能找到〔第三条〕。 |
| ISTP · 猫 | 你独来独往，但〔什么都会〕。 |

4. 收藏卡同样：类型 · 动物名 + 这一句话。
5. **所有文字放在画面左下方或左侧的暗处，绝不能压到动物的身体、头部和月亮**（片头概念大字在画面上方中央，也不能压到月亮）。
6. 字体：思源宋体 Heavy / Bold（Noto Serif CJK SC），MBTI 字母 Cinzel 900；片头大字 64px，字幕（一句话）52px，标签 / 剪影下的类型字母 44px，左上角 logo 34px。文字最亮不超过 #EBEBEB。

## 5. 构图

- 经典的“**对月嚎叫**”构图是系列的招牌：一轮巨大、明亮的满月在动物身后，**直径约为画面高度的 70%**，月面有淡淡的纹理，边缘发光，**完整在画面内**；动物在画面中**偏右**，做专属动作时抬起的头和张开的嘴正好叠在月亮前面，形成清楚的剪影。
- 月亮钉在镜头上（屏幕位置、大小固定）；动物用“眼睛中点在屏幕上的位置”来摆（`episode.frame.eyes`）。
- **头部后面不要圆形光环**（和月亮重复）。觉醒的能量冲击从**月亮**向外爆开。
- 左上角常驻小 logo“兽格觉醒”。

### 6.2 背景

抽卡阶段背景只有深色、细小的星点和少量飘浮的粒子。**不要月亮、不要圆圈、不要大的几何图形。** 月亮第一次出现在镜头冲进主角卡面的那一刻；结尾月亮淡出。

### 6.3 开头 + 觉醒时间线（全部按实测节拍；一拍 E ≈ 0.333 秒，4 拍一小节）

- **T_REVEAL** = 第 4 小节第一拍（原曲 3.996 秒，第 120 帧）：主角卡翻面亮相。
- **T_AWAKE** = T_REVEAL 之后的下一个小节第一拍（原曲 5.329 秒，第 160 帧；也是低音鼓进来、乐句开头）：觉醒、叫声。

| 时间（原曲） | 画面 | 声音 |
|---|---|---|
| **第 0 帧**（完整画面） | 画面正中央一叠很精致的卡牌：卡背朝上、有厚度，**高度约为画面的 35%**；牌堆周围一圈缓慢旋转的金色粒子，顶部的卡轻轻浮动（周期整除成片时长）；上方大字（64px，白色，“动物”用主色）“每一种 MBTI，都有一只对应的动物” | 歌曲第一个音 |

**律动**：任何 0.5 秒内画面都不能静止（发牌、转盘每拍都有变化；停留那一小节靠全息光泽、眼睛、粒子和极轻的推近）。

配置：`episode.cards = { deal: [3,3,3,3,2,2], jumps: [[拍, 卡序号], …], popBeat: -1 }`（拍以 T_REVEAL 为 0；卡序号按上表从 0 到 15），`music = { reveal, awake }`。

### 6.4 正文（约 14–15 秒，16 集都用这个结构）

三段：**误解 → 动物的真实冷知识 → 一句让人心里一热的话**。

1. **字幕**：画面下方中央，52px，白色，关键词用这一类的颜色，带暗色渐变底；在拍点上弹出（85% → 105% → 100%，0.2 秒）。每条显示时长 **≥ 1.0 + 0.17 × 字数**（字数不计标点）秒；切换对齐拍点，只能往后延；需要“小节第一拍”的地方延到下一个小节第一拍。字幕绝不压到动物的头和眼睛。
2. **画面**：每一段都要有画面上的动作，跟着节拍律动；任何 0.5 秒内画面都不能静止（镜头始终在缓慢移动）。
3. **不说教**。知识只用规定的说法，不自己添加数字或研究。
4. **转场**：场景之间用粒子流动 / 镜头连续运动衔接，主体不能消失超过 0.3 秒。
5. 正文开始时，“类型 · 动物名”和那一句话移到左上角变成小标题（一句话读完再淡出，小标题在第 3 段前淡出），给下方字幕让位。
6. 时间（由 `main.js` 的 `timeline()` 按字数和节拍自动算）：第 1 段从动作收回的那一拍开始；第 2 段的两条字幕、第 3 段、结尾都从小节第一拍开始。

INFJ · 狼（`episodes/wolf.json` 的 `story`）：

| 段 | 字幕 | 画面 |
|---|---|---|
| 1 误解 | 别人总觉得你太〔安静〕、太〔难懂〕。 | 镜头从近景拉远：狼站在突出的岩石上，大月亮在身后；左侧远处山脊上 5–6 只灰暗的狼影（同一个狼模型，灰色、亮度 20%、半透明、约主角 1/4 大），挨在一起、背对我们的狼；狼毛被风吹动，眼睛一闪一闪 |
| 2 冷知识 | 野外的独狼，大多是〔主动离开〕狼群，／去找〔真正属于自己〕的地方。 | 字幕 1 的小节第一拍：狼转头看向画面右侧，狼群影子淡去、化成粒子飘散。字幕 2 的小节第一拍：狼脚下亮起一条发光的粒子小路，每一拍延伸一段，通向右边远处的山脊，顶端亮起柔和的绿色光点；镜头跟着光路横移，狼保持在画面左侧三分之一 |
| 3 一句话 | 你不是不合群，你只是在等〔真正懂你的人〕。 | 小节第一拍：镜头推到狼的脸部特写（侧面，月光勾出轮廓），眼睛亮起；下一拍：右侧远处地平线亮起另一双狼眼（白绿色），慢慢清晰；再下一拍：两双眼睛一闪，中间一缕很淡的粒子光连起来再散开 |

### 6.5 结尾（约 4 秒）

1. 小节第一拍：动物和月亮缩小，粒子聚回卡框，定格成收藏卡（和翻面亮相的同一张），卡下方大字（56px，白色，“@ 他”用主色）“你身边有这样的 INFJ 吗？@ 他”，停留 ≥ 1.6 秒。
2. 下一个小节第一拍：卡飞回 4×4 网格中自己的位置，**保持正面朝上**（已揭晓）；下一集的卡亮起一圈它那一类颜色的光，卡上方小字“下一集”，网格上方大字换成“下一集：INTP”（类型用下一集那一类的颜色）。
3. 最后约 0.5 秒：16 张卡收回成一叠（揭晓的那张翻回背面），大字换回“每一种 MBTI，都有一只对应的动物”，回到第 0 帧，循环无缝。

## 7. 专属动作 + 专属叫声的空间（每只都必须有）

1. 动作用**模型骨骼**做（`episode.action.bones`：骨骼链从根到梢，每根给抬起角 `pitch` / 转向角 `yaw`），在着色器里逐帧蒙皮（暗色剪影遮罩用同样的骨骼矩阵），平滑、不变形。节奏按拍：抬起 `rise` 拍 → 保持 `hold` 拍 → 收回 `back` 拍。
2. 声波：从嘴部向外扩散 3–4 圈粒子弧（朝向镜头，像“(((”），每拍一圈，落在拍点上。
3. 叫声与音乐让位见 1.1。

| 动物 | 类型 | 专属动作（骨骼） | 叫声 | 声波 / 目标 |
|---|---|---|---|---|
| 狼 | INFJ | **对月嚎叫**：头从平视抬起约 35°（颈 + 头），下颌张开，保持后收回 | 狼嚎 | 弧形声波从嘴部扩散到月亮上 |
| 猫头鹰 | INTP | **张开翅膀**：双翼展开到最大，头转向镜头，眼睛睁到最圆 | 低沉的“呜—呜” | 声波化成星轨上的波纹，符文亮起 |
| 狐狸 | ENTP | **回头**：头和颈向镜头回转约 50°，嘴角微张，尾巴一甩 | 短促的狐叫 | 声波推动扇形狐火依次蹿高 |
