## 我自己觉得还可以更好的地方

1. **胶片段的格子偏小**（352 px 宽）。五格的差异（外套颜色、雨、孩子的位置）能看出来，但在手机上要盯一下。整片里可以在 20 s 后加一个轻推，让最后两格放大
2. **人物没有表情**。现在是侧脸剪影式，安全、统一，但「那句话很冷」「表情被改了」这类细节在后面（P3 / P5）需要用台词卡和光线来表达，而不是五官
3. **3.0 s 的错层**是全片唯一的「故障感」。我刻意只用一次；如果你觉得太像特效，可以去掉，只留双重影像的呼吸
4. **4.4–8.8 s 的回忆全屏**节奏偏安静（只有缓推和雨）。这是为了让观众把自己的回忆「放进去」；如果想更快，可以把「你一直记得：」去掉，直接上第二句，整体提前约 1.5 s
5. **「确定」印章**目前压在记忆画面的地毯上，红色和红外套呼应。若希望更狠，可以在 15 s 让照片那张慢慢暗下去，只剩盖着「确定」的那张
6. 字幕和印章同时说「确定」——是有意的重音；如果觉得重复，可把字幕改为「却比任何时候都笃定。」

## 需要你确认

- 前 20 秒的方向（同一段回忆贯穿全片：被怀疑 → 被比对 → 被一次次重写）是否可以
- 片长：完整分镜设计为 119.8 s（`docs/memory/storyboard.md` 文末有压到 112 s 的方案）
- 确认后继续 P2–P6、封面、全片关键帧
