## 我自己觉得还能更好的地方

1. **P2 聚会**：人物是简化的头和躯干，「所有人看你」靠正脸和两只眼睛表达；如果觉得不够诡异，可以让正脸更多、更近
2. **P4 实验卡和考卷**是全片最亮的物体（米色纸）。符合「主体清楚」，但如果你想更统一，可以把纸压暗一档
3. **T（89.6 s）是暂定的**：拿到《千年之后》后用 `MAIN_BEAT_T=实际秒数 node src/render.js --video memory …` 整体对齐
4. 38–44 s 档案窗口的历史版本叠在左上方，文件名会叠在一起；它表达「一层层保存」，但细看有点乱
