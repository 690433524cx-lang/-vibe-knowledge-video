# 《你最确定的那段回忆，可能是你自己编的》分镜表

认知纪录片 / 视觉散文 · 1920×1080 / 30fps / H.264 · 设计总长 **119.8 s**（可压到 112 s，见文末）

- **无口播、无背景音乐**。只有极轻的环境声和拟音（翻照片、纸、铅笔、印章、放映机、雨），给后期《千年之后》留空间
- **MAIN_BEAT_T = 91.4 s**（暂定）：全片最狠的一句「而是你后来一遍又一遍，讲给自己的那个版本。」。拿到音乐后用 `MAIN_BEAT_T=…` 整体对齐
- 字幕：固定在下方安全区、水平居中、暖白、比上一期再慢一点（每句 ≥ 1.8 s，两行 ≥ 3.0 s）。只有三处中央排版：「确定」印章、「其实，你是在重建。」、T 句
- 科学表达：只说「心理学实验发现」，不放学者照片、不写人名，实验用档案卡 / 问卷卡呈现

## 视觉体系

| 项目 | 规定 |
|---|---|
| 一个贯穿全片的「母题」 | **同一段回忆**：旧客厅，门口站着妈妈，孩子站在沙发前，窗外在下雨，妈妈穿红外套。全片反复回到它——它被怀疑、被比对、被一次次保存、被越讲越锋利，最后被放下 |
| 两个版本 | **记忆版**：暖、柔、边缘发光、在下雨、红外套、孩子在左边；**照片版**：中性偏冷、清楚、晴天、藏青外套、孩子在窗边。两版只差几个细节，观众一眼能比出来 |
| 空间 | 深夜书桌 / 档案桌：暖黑底、一盏台灯的局部暖光，其余压暗但不死黑（手机上能看清） |
| 档案元素 | 照片白边上的手写、铅笔圈、红色印章、打字机小标签、问卷卡、文件名 memory_01 … memory_07 |
| 颜色 | 低饱和；红色只给「红外套」和「确定」印章两处，越到后面越少 |
| 禁止 | 真实人物照片、学者照片、满屏 UI、故障特效乱闪、粒子、3D 大字、左右乱跳的字幕 |

## 统一色彩系统（v0.2 补充，脚本 / 镜头 / 字幕 / 节奏不变）

**原则：背景暗，主体清楚。** 不把整个画面一起压黑；只压环境，人物、手、照片、关键物体始终在光里。

| 角色 | 颜色 | 占比 / 用法 |
|---|---|---|
| 主色 | 黑 / 炭黑 / 深灰 / 深褐 / 极深蓝灰 | 画面约 70–80%（逐帧检查：亮度 < 60 的像素占比 ≥ 70%） |
| 辅助 · 暖白 / 米白 | `#efe6d3` `#e8dfcc` `#e4d8c0` | 字幕、核心文字、照片白边（白边压到 `#d2c9b6`，不刺眼） |
| 辅助 · 少量暖黄 | 局部光 `rgb(246,204,156)`、台灯 | 只落在人物、照片、灯附近，不铺满背景 |
| 辅助 · 少量暗红 | 外套 `rgb(158,44,34)`、印章 `#a5342a`–`#b23a2c`、字幕强调 `#b5493d` | 只给「记忆被修改 / 错误细节 / 关键强调」 |
| 照片版本 | 中性偏冷的深灰蓝，晴天也是低饱和暖灰 | 与记忆版形成冷 / 暖对照，但两者都在深色体系里 |
| 记忆版本 | 稍微偏暖的深褐，边缘化进黑暗，光晕很小 | 不切成明亮插画 |

**做法**
- 客厅：墙、地板、沙发、窗帘、门全部降到炭黑 / 深褐；环境整体再压暗一层，只在妈妈、孩子、窗的位置留局部暖光；门洞深处一点暖光，让妈妈的头和肩在暗处仍有轮廓
- 人物：自身受光不衰减，轮廓光加强（rim 0.75–0.8），手机上可辨
- 雨天窗外：极深蓝灰；晴天窗外：低饱和暖灰绿，不再是浅黄大色块
- 胶片小格：单独提亮（格子小，必须看得清差别）
- 禁止：大面积浅黄 / 米黄背景、明亮蓝紫、霓虹、高饱和、赛博朋克感

## 前 20 秒核对

| 要求 | 怎么做 |
|---|---|
| 第 0 秒完整出现核心句 | 第 0 帧就是两行完整大字，没有淡入 |
| 观众立刻知道在讲「记忆不可信」 | 第 0 帧的照片就是双重影像，外套颜色在两个版本之间呼吸 |
| 至少 3 次明确变化 | 桌面照片 → 进入回忆（4.2）→ 真实照片压上来（8.8）→ 左右比对 + 圈错（10.4）→「确定」印章（13.9）→ 胶片（16.2）→ 五格漂移（18.0）= 6 次 |
| 生活感 + 概念感 | 客厅 / 妈妈 / 雨是生活；印章、胶片、「第 N 次想起」是概念 |

## 时长说明

- 用户给的 6 段参考时间是 0–12 / 12–32 / 32–52 / 52–75 / 75–98 / 98–118。本片按「0–20 秒样片节奏」把「因为记忆不是录像」的**预告**放到了 16–22 秒，所以各段整体后移约 4–6 秒
- 若要压到 112 s：去掉 P2 收束的第一句（-2.2 s）、P4「记忆不是把过去保存下来」与上一句合并（-2.3 s）、P6 两组两行句各缩 0.5 s，结尾提问停留 3.2 s
