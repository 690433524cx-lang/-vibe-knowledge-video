# 《想看清一个人，别看他说什么》分镜表

人性观察 / 社会心理 / 行为判断 · 1920×1080 / 30fps / H.264 · 目标总长 **118 s**

- **不是读心术、不是微表情教程、不是操控术。** 全片只讲一件事：一个动作看不穿一个人；跨时间、跨场景反复出现的选择，比他怎么描述自己更有信息量
- **无 BGM、无旋律**：只有环境人声、杯子、账单夹、手指敲桌、门、键盘、办公室底噪、呼吸、非旋律低频冲击，给后期音乐留空间
- **MAIN_BEAT_T = 98.0 s**（暂定）：「是一个人反复做出的选择。」。拿到音乐后用 `MAIN_BEAT_T=…` 整体对齐
- 字幕：普通字幕**固定在下方安全区、水平居中**；居中的只有「有东西可以争的时候」「不需要你的时候」「压力最大的时候」「反复做出的选择」和最后两句。短句 ≥ 1.6 s，中句 2–3 s，金句约 3 s
- 动态原则：**每 2–4 秒至少一次有意义的视觉事件**（换字幕不算）。每个场景都有前景 / 中景 / 背景三层视差
- 场景之间连续变形：账单 → 三个物件 → 三扇门 → 会议室 → 奖金 / 蛋糕 → 手机头像 → 聊天框 → ERROR 红框 → 进度条 → 时间轴 → 回到餐桌

## 视觉体系

| 项目 | 规定 |
|---|---|
| 母题 | **同一张餐桌、同一个人**：A，驼色毛衣，开场说「我这个人其实不太在乎钱」。全片最后回到这张桌子 |
| 人物 | 代码绘制的侧面人物（真实比例、简化五官），有眼、眉、嘴：笑、说话、低头看账单都能读出来。不画恐怖面具，不画夸张表情 |
| 手 | 特写里单独绘制的手（四指 + 拇指 + 针织袖口），能敲桌、悬停、收指、推东西——「一双手在做选择」 |
| 颜色 | 70–80% 炭黑 / 暖黑 / 深褐 / 极深蓝灰；10–15% 暖白 / 米白（桌布、小票、字）；5–10% 局部暖黄灯光；3–5% 暗红 / 铜金只给金额下划线、红酒、ERROR、钱 |
| 光 | 背景暗、主体亮。每个空间有自己的光源：餐厅吊灯、后厨门洞；会议室长条灯、窗外冷色城市光；办公室显示器 |
| 禁止 | 读心术图标、HUD、赛博朋克、扁平 UI 图标墙、满屏闪烁、好人 / 坏人二分 |

## 封面

黑底；中间一个人物，面前一层「说话时的形象」（暖白轮廓，像被灯照亮的那一面）；身后三个极暗的场景轻轻融在背景里：钱、服务员、压力（ERROR 的一点红）。主标题「想看清一个人」，第二行小一号「别看他说什么」，暖白，极简。
