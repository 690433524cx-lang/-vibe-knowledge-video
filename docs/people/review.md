## 运动规则：逐帧测量

把样片缩到 192×108 灰度、每 0.1 s 取一帧，计算每个 1 秒窗口首尾两帧的平均像素差：

- **0–21.3 s：没有一个 1 秒窗口低于 1.5 / 255**，即没有任何「连续静止超过 1 秒」的画面
- 唯一低于 1.5 的窗口在 22.8–23.7 s（第一章标题压暗、镜头慢转），在开场 20 秒之外；继续做第一章时会把这里的动作加密

同时存在的运动层（每一段都至少两层）：

| 段 | 镜头运动 | 主体运动 | 空间变化 |
|---|---|---|---|
| 握手 / 拍肩 | 横移、上摇、下甩 | 握手摇动、拍肩、手滑落 | 侧面空间 → 俯视桌面 |
| 筹码 | 推进 + 旋转 | 筹码滑入、手指拖动、对方拨走 | 筹码 → 盘子 |
| 餐厅 | 拉远 + 旋转 + 跟拍 | 服务员走、客人笑、敲桌、推盘子 | 盘底 → 钟面 |
| 办公室 | 退镜头、推近、晃动、绕半圈 | 打字、电话、打印、消息、咖啡倒、站起来 | 办公室从钟周围长出来；柱子擦过换到反打 |
| 回流 | 甩到钟面 | 秒针 → 手，扫三圈 | 每一圈扫出一个新场景 |
| 拉远 | 缩成圆、圆在转 | 字浮出、被撞碎 | 黑暗空间 → 圆放大成会议室 |

## 20 秒内的数量要求

| 要求 | 实际 |
|---|---|
| ≥ 3 次明显镜头运动 | 8：跟拍上摇 / 下甩、推进筹码、旋转拉远、跟拍盘子、从钟面退、绕半圈、甩向钟、拉远成圆 |
| ≥ 3 次物体形态转换 | 6：筹码 → 盘子、盘底 → 钟面、秒针 → 手、手 → 敲桌的手指、手指 → 指人的手、画面 → 圆 |
| ≥ 2 次空间变换 | 4：侧面 → 俯视桌面、办公室从钟周围长出来、柱子擦过到反打、黑暗空间 → 会议室 |
| ≥ 3 次人物行为变化 | 5：寒暄拍肩 → 抢筹码 → 对服务员不抬头、敲桌推盘 → 慌乱碰倒咖啡 → 站起来指向同事 |
| ≥ 1 次视觉高潮 | 19.2–19.65：三个「真实动作」的圆冲过去，把四句自我评价撞碎 |

## 字幕

- 全部在下方同一位置；只有「看他反复怎么选择。」和第一章标题居中
- 0–3 s 两行字幕第 0 帧完整可读；最短一句 1.55 s（「因为人最难伪装的，」），其余 2–3.5 s

## 声音

无音乐、无旋律：笑声、握手摩擦、拍肩、筹码滑行、餐厅人声、脚步、两下敲桌、越来越密的滴答、电话 / 键盘 / 打印 / 杯子倒、三圈扫过的风声、字碎的颗粒声和一次低频冲击。平均 −38.1 dB，峰值 −15.0 dB。

## 我自己觉得还能更好的地方

1. 握手和拍肩用的是代码画的手和简化的人物，近看比较「平」；如果要更像实拍，可以给握手加更多皮肤明暗和指节细节
2. 俯视的餐厅里人物是头顶和肩膀，读得出「谁朝着谁」，但看不到表情；「没抬头」靠头的朝向和那只手表达
3. 三个圆里的画面比较小；它们的作用是「这些动作都还在」，撞字那一下才是重点
4. 第一章的标题段（22–24.5 s）相对安静，下一轮做第一章时会把动作加密
