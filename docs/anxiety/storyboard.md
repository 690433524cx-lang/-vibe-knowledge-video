## 一、核心设计

| 项目 | 规定 |
|---|---|
| 唯一运动主体 | **NOW 金色光点**（世界坐标 `[-700,-40,1000]`）。0 s 出现，全片不消失；128 s 镜头原路返回到它 |
| 空间 | 一个连续的 3D 黑色信息空间：x 向右、z 向深处 = 从「现在」走向「未来」。所有知识对象都留在这个空间里，**全片不清屏、不黑场切页** |
| 空间纵深 | 远处地面网格（极淡）+ 稀疏坐标十字 + 静止的数据点（只随相机产生视差，不乱飘）+ 节点分布在不同深度 |
| 视觉语言 | 节点 = 内核 + 光晕 + 环；**虚线环 = 还没发生的未来**；实心 = 已经存在；线上流动的光点 = 数据/信号 |
| 颜色 | 底 `#050505`；文字暖白 `#ece6da`；节点暗金 `rgb(205,164,92)` / 暖金 `rgb(250,218,156)`；**暗红** 只给最坏结果、身体警报；**绿色**（<5%）只给「现实 / 已经确定的事实」 |
| 字体 | 中文 Noto Sans SC（300/400/500）；英文、读数 JetBrains Mono（等宽、宽字距） |
| 禁止 | 蓝紫霓虹、HUD 框、乱码、故障特效、AI 人物、写实人体、爆炸、震屏、360° 旋转、CTA |
| 相机 | 只因知识关系而动：**跟信号 / 钻进节点 / 拉远揭示 / 结构变形 / 小幅环绕视差**（≤ 3°） |
| 字幕 | 普通字幕固定下方安全区（50 px），10–16 字 ≥ 2.5 s，长句 3–4 s；五句「视觉锚点」可离开底部 |
| 声音 | 无音乐、无口播。代码合成：空间底噪、分叉信号音、脉冲、心跳、呼吸、张力、相机气流、汇聚长音 |

### 贯穿全片的知识闭环（结尾必须由前面出现过的节点组成）

```
现实出现未知 → 大脑预测未来 → 多个可能 → 威胁结果获得更多注意 → 灾难化推演
   ↑                                                                    ↓
再次预测 ← 新的未知 ← 短暂安心 ← 寻找确定 ← 焦虑感上升 ← 身体提前进入警戒
```

每个节点首次出现的位置：UNKNOWN（S1）· PREDICTION（S5）· 多个可能（S6）· 注意权重（S6）· 灾难树（S7–S8）· 身体警报（S2/S9）· 寻找确定 / 短暂安心 / 新的未知（S11）。S16 把它们按原位置连成一圈。

### 速度曲线

`0–5 s 最快` → `5–35 s 中快持续推进` → `35–80 s 快慢交替（灾难树快、结论停）` → `80–115 s 中速` → `115 s 后明显减速`

### S1 · 0.0–2.0 预测启动 ✅样片
- **字幕**：第 0 帧完整：「事情还没发生，／你已经先痛苦了一遍。」（hook 76 px，下方，至 2.5 s）
- **中心对象**：NOW 金点 → 预测树
- **画面结构**：左侧 NOW；前方黑色空间；顶部一条极淡阶段刻度 `NOW — UNKNOWN — PREDICTION — POSSIBLE FUTURES`，随信号依次点亮
- **节点关系**：NOW → UNKNOWN（空环）→ 3 → 7 → 15 个末端（虚线环）→ 1.0–1.9 s 每个末端再长 2–3 根微分支（共 ~37）
- **末端标签**（半透明）：失败 / 被拒绝 / 搞砸 / 出问题 / 关系恶化 / 失去机会 / 最坏结果
- **镜头**：第 0 帧就在动；1–2 s 轻推进网络内部（x +190，z +230）。**最快**
- **信号**：0.0 金色信号已经离开 NOW；0.2 分 3；0.42 分 7；0.68 分 15；每根线的生长头有亮点；线上开始有数据点流动
- **新增**：未来分支 1→3→7→15→37
- **保留**：NOW
- **转场**：无（同一空间）
- **音效**：0.0 一声干净信号音 + 底噪；0.2/0.42/0.68/0.9 升调分叉音；1.0 一串越来越密的细信号
- **回答**：事情还没发生时，脑子在干什么？——在不停地分叉出未来
- **留下**：这么多未来，哪个会被看见？

### S2 · 2.0–7.0 最坏结果 → 身体警报 ✅样片
- **字幕**：「明明什么都还没发生。」（2.9）／「身体却已经开始反应。」（4.75）
- **中心对象**：五种结果 → 最坏结果 → 身体四节点
- **画面结构**：右侧一列五个结果（没事 / 一般 / 有点糟 / 失败 / 最坏结果），末端标签淡出，所有末端被「归类」连到五个结果；4 s 后最坏结果在上、身体四节点在下
- **节点关系**：2.0–2.4 五个结果**等大**出现 → 2.4–3.1 权重改变：没事、一般缩小变暗；有点糟保持；失败放大；**最坏结果最大并染暗红**，通往它的线变粗、有暗红数据流
- **镜头**：3.05–3.85 **冲向最坏结果**（PUSH INTO NODE，其他分支被甩到背景）；3.9–5.0 **跟着脉冲向下**（FOLLOW THE SIGNAL）；5–6.5 停住，极小环绕视差（yaw 0.05）
- **信号**：3.55 / 3.78 最坏结果两次脉冲（暗红 → 暖金）；3.92 脉冲向下穿过空间到「身体警报 BODY ALERT」，再分四路
- **新增**：心率（心电线变密）4.3 · 呼吸（变浅变快）4.5 · 肌肉张力（条形上升）4.7 · 警觉（LOW→HIGH）4.9；全部亮起后每 0.9 s 同步一次克制的脉冲
- **保留**：整棵树在背景（压暗 60%）
- **转场**：无
- **音效**：2.4 下沉低音（注意偏移）；3.55 闷脉冲；4.3 心跳（之后 5.15 / 5.85 / 6.45 继续）；4.5 浅呼吸；4.7 张力低音；4.9 高音提示
- **回答**：什么都没发生，为什么会难受？——最坏版本被放大，信号直接送进了身体
- **留下**：这只是我一个人吗？

> **前 5 秒完成**：现实（NOW）→ 预测（分叉）→ 最坏结果（被放大）→ 身体警报（四节点亮起）。

### S3 · 6.6–13.4 生活里的四个未知 ✅样片
- **字幕**：「你是不是也经常这样？」（7.45）／「一个答案都还没有。」（10.15）／「脑子已经替你演完了后面十集。」（12.4，语气轻）
- **中心对象**：四个「未知」事件
- **画面结构**：沿身体警报金线**高速反向回溯**（6.6–7.2），然后从右向左匀速掠过四个漂浮在同一空间里的事件；树和身体节点留在背景、产生视差
- **节点关系**：事件 = **现实**（绿色小内核：这句话确实发生了）；经过时自动长出三步推演（金色虚线环）
  - 明天考试 → 会不会考砸？→ 是不是复习错了？→ 是不是全完了？
  - 老板：“明天来找我一下” → 是不是做错了？→ 是不是要批评我？→ 是不是工作出问题了？
  - 体检结果还没出来 → 会不会有问题？→ 要是很严重呢？→ 家里怎么办？
  - 消息还没回复 → 是不是生气了？→ 是不是我说错话了？→ 关系是不是要变了？
- **镜头**：回溯快（ease-in）→ 掠过匀速（400 u/s）→ 12.4–13.4 **拉远揭示**，同时看见四个事件 + 推演 + 原来的树 + NOW。**中快**
- **信号**：推演链一节一节生长（每节 0.3 s），之后数据点沿链流动
- **新增**：四个生活事件 + 12 个推演
- **保留**：NOW、预测树、最坏结果、身体警报（背景）
- **转场**：无
- **音效**：6.55 反向气流；每个事件出现一声低信号音 + 三下「嗒」
- **回答**：这只是我吗？——每一个「未知」都会自动生成很多「未来」
- **留下**：这件事有名字吗？

### S5 · 16.9–25.0 进入大脑预测系统 ✅样片（至 20 s）

### S6 · 25–38 多种未来 ≠ 同样被注意（第一次模型高潮）
- **字幕**：「未来，本来有很多种可能。」／「但焦虑时，最坏的那个版本，往往最容易抓住你的注意力。」／「注意——」（停 0.3 s）／「不是它真的更可能发生。」／「只是它在你的脑子里，变得更大了。」
- **中心对象**：「明天」节点分裂出的五个未来（很好 / 还不错 / 普通 / 有点糟 / 最坏）
- **画面结构**：五个节点**等大等色**横排；右侧两组竖条：`ACTUAL POSSIBILITY 实际可能性`（不变）与 `ATTENTION WEIGHT 注意权重`（LOW → MEDIUM → HIGH，不放假数字）
- **节点关系**：很好、还不错、普通缩小；有点糟略大；最坏快速变大；注意权重柱随之剧变，实际可能性柱**纹丝不动**
- **镜头**：钻进「明天」节点（PUSH INTO NODE）→「注意——」时停 0.3 s → 轻微拉远露出两组柱
- **信号**：注意力的数据流越来越多地流向「最坏」
- **新增**：中央 `概率 ≠ 注意力`；说「大」时最坏节点再扩一次
- **保留**：预测核心（远景）、时间轴
- **转场**：无
- **音效**：权重变化的下沉音；「注意——」处全部静音 0.3 s
- **回答**：最坏结果是不是更可能？——不是，只是更占注意力
- **留下**：一个担心，最多能长多大？

### S8 · 52–66 灾难化思维
- **字幕**：「心理学里，这种不断把可能性推向最坏结局的过程，／常被称为灾难化思维。」

- **画面结构**：网络不消失；镜头**穿过分支**一路向最深处：被批评 → 被辞退 → 失败 → 以后怎么办 → 彻底完了 → 最坏结果；到达后才出现 `CATASTROPHIZING 灾难化思维`

- **信号**：最坏结果持续释放脉冲；最后一道脉冲**穿过镜头**
- **新增**：理论名称 2

- **转场**：脉冲穿过镜头 → 进入身体警报系统

- **回答**：这叫什么？——灾难化思维

### S10 · 80–90 最核心认知反转：可能 ≠ 正在发生
- **字幕**：「提前焦虑最折磨人的地方。」／「不是你真的看见了未来。」／「而是身体，开始为一个‘可能的未来’提前付费。」
- **中心对象**：中间巨大的 `≠`
- **画面结构**：人体缩到左侧；右侧 `REALITY 现实`：事件尚未发生（绿色，空）；另一侧 `PREDICTION 预测`：失败 / 批评 / 失去 / 最坏结果 / 身体警报；中间 `≠`；出现极简 `ENERGY COST 注意 / 身体成本` 刻度条被持续消耗（不做钱）；最后全部简化为**锚点**：`可能 ≠ 正在发生`
- **镜头**：拉远并排 → 推向 ≠ → 结构简化（MORPH）
- **信号**：身体成本条的数据流从人体流向「可能的未来」
- **新增**：现实 / 预测并置；成本
- **保留**：人体、最坏结果、身体警报
- **转场**：结构变形
- **音效**：底噪收窄，只剩心跳
- **回答**：焦虑到底在消耗什么？——为一个可能的未来提前付费
- **留下**：为什么停不下来？

### S11 · 90–105 确认回路：对不确定性的低耐受
- **字幕**：「于是，人会本能地想把未知消灭掉。」／「问题是，确定感往往只维持很短时间。」／「新的未知，很快又出现。」
- **中心对象**：UNKNOWN（就是 S1 那个空环）
- **画面结构**：UNKNOWN → ANXIETY 焦虑 → CHECK 确认 → TEMPORARY RELIEF 短暂安心 → NEW DOUBT 新的疑问 → UNKNOWN；CHECK 旁依次亮「再查一次 / 再确认一下 / 再想一遍 / 再问一次」，计数 ×1 → ×2 → ×4 → ×8；RELIEF 亮 1 s 后熄灭，UNKNOWN 重新亮起，回路自动再跑一圈
- **镜头**：跟着回路里的信号绕一圈 → 持续拉远，发现小回路其实是一个巨大的圆 → 中央 `INTOLERANCE OF UNCERTAINTY 对不确定性的低耐受`
- **信号**：每条线都有信号在流动
- **新增**：理论名称 3
- **保留**：UNKNOWN、焦虑（命名节点）
- **转场**：无
- **音效**：确认的「嗒」越来越密；安心一声柔音后断
- **回答**：为什么一直确认还是不安？——确定感很短，新的未知马上来
- **留下**：我们到底在怕什么？

### S12 · 105–116 真正让人受不了的是「不知道」
- **字幕**：「有时候，真正让人受不了的。」／「甚至不是坏结果本身。」／（停顿）／「而是——我不知道会发生什么。」
- **中心对象**：「不确定」节点内部
- **画面结构**：两个等大节点：坏结果 / 我不知道结果 → 坏结果缩小，「我不知道」变大，向外生成：无法控制 / 无法准备完全 / 无法保证 / 没有答案
- **镜头**：钻进「不确定」节点（PUSH INTO NODE），中速
- **新增**：不确定本身就是压力来源
- **保留**：确认回路（背景）
- **转场**：无
- **音效**：极简，底噪
- **回答**：怕的是结果还是未知？——常常是未知本身
- **留下**：那怎么办？

### S13 · 116–128 解决方向：允许暂时没有答案
- **字幕**：「减少提前焦虑，不是强迫自己相信‘一定会没事’。」／「而是重新允许——」／「一个问题，暂时没有答案。」
- **中心对象**：重新打开的未来分支
- **画面结构**：五个未来重新等大：很好 / 普通 / 不确定 / 有点糟 / 最坏；「一定会出事」出现被一条金线划掉；「一定会没事」出现也被划掉；只留「我现在还不知道。」
- **镜头**：**明显减速**；说到最后一句时，全片所有网络第一次明显慢下来（高速计算 → 缓慢运行）
- **新增**：第三种态度（不是乐观、不是悲观）
- **保留**：预测核心、五个未来
- **转场**：无
- **音效**：底噪变暖、变慢
- **回答**：怎么减少？——允许暂时没答案
- **留下**：（无，进入收束）

### S14 · 128–136 原路返回到 NOW
- **字幕**：「你刚刚在脑子里经历了那么多。」／（停顿，镜头稍拉远）／**锚点句**：「现实，其实一步都还没走。」
- **中心对象**：NOW（第 0 秒那个金点）
- **画面结构**：所有图谱向远处退去；镜头原路穿过：身体网络 → 灾难树 → 可能性网络 → 预测系统 → 回到 NOW；NOW 仍在原地，前方仍是黑的；所有未来分支熄灭，只剩 NOW 和前方 UNKNOWN
- **镜头**：快速回溯（倒放式穿行）→ 停在 NOW
- **新增**：反差：经历很多 vs 一步没走
- **保留**：NOW、UNKNOWN
- **转场**：回溯即转场
- **音效**：反向气流 → 安静
- **回答**：现实走了多远？——一步都没走

### S15 · 136–143 结论
- **字幕**：中央锚点 `可能 ≠ 正在发生`（停 2 s），小字 `ANTICIPATORY ANXIETY 预期性焦虑`；最后：「未来还没发生。」／「别让预测，先替现实活一遍。」
- **画面结构**：从 NOW 只向前出现一条很细的线：现在 → 等事情真正发生 → 再处理（不是建议清单）
- **完整闭环**（S16，137–141 叠在最后）：镜头最后一次拉远，S1–S13 出现过的节点在各自原位置被一条金线串成闭环（见上方闭环图），1.5 s 后收回到 NOW
- **镜头**：极慢拉远 → 停
- **音效**：只剩极轻底噪，最后一声信号音
- **结束**：不要 CTA，淡出
