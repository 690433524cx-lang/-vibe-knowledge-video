# 《时间错觉》时间轴（v1.0 · 完整片 120.0 s）

1920×1080 · 30 fps · H.264 · **MAIN_BEAT_T = 65.0 s**（暂定，未指定 BGM）

- 当前没有 BGM：成片只有环境声、关键音效和 T 处一个低频冲击，因此「完整成片」与「无 BGM 成片」是同一个文件 `output/time/full_v1.mp4`
- 拿到歌曲后：`MAIN_BEAT_T=<秒> node src/render.js --video time --music <音频> --out output/time/final.mp4`，T 前后 2 秒刚性对齐，其余按比例伸缩
- 普通字幕：下方安全区、水平居中、暖白，66 px（比 v0.2 放大约 18%），两行用「\n」
- 锚词：「第一次」31.5 s、「重复」54.8 s、「时间没有加速。」65.0 s、「是重复，让它消失了。」66.9 s（画面中央排版）
