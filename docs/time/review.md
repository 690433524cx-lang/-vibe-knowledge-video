## 最终验收标准

| 检查点 | 结果 |
|---|---|
| 前 3 秒是否马上产生共鸣 | 第 0 帧就是夏天的窗、光、灰尘、孩子和「7 月」日历；3 秒内已经闪过冰棍、雨、晚霞 |
| 前 20 秒是否至少 4 次明显信息变化 | 窗边 → 暑假碎片 → 日历 → 月份被吞掉 → 五天复制 → 残影 → 场景叠合，共 7 次 |
| 30 秒是否从生活进入解释而不像 PPT | 「第一次」是生活镜头横移；解释发生在挂着这些照片的走廊里，再自然地变成时间轴 |
| 60 秒是否有明显累积感 | 365 页铺满整个桌面，然后一段段压缩 |
| MAIN_BEAT_T 是否绝对高潮 | T-1.0 收拢、T-0.5 几乎消失、T-0.2 暗场；T 那一帧整句出现，只有一次低频冲击；第二行 1.9 s 后出现 |
| 80–100 秒是否有新认知 | 年龄比例（并明确说「往往不只是年龄」）→ 相册里「活过的半年只剩几个画面」→ 空墙 |
| 100 秒以后是否情绪收束 | 节奏放慢：同一节地铁里抬头、雨、画画的孩子；结尾回到开头的窗，打开窗 |
| 最后一句是否有余味 | 「这一生，才会显得更长。」停留约 2.6 s 后淡黑，没有 CTA |

## 科学表达

- 只讨论「回顾时的时间感」，用词统一为「可能 / 往往 / 更容易 / 回头看时」
- 没有引用任何具体实验数据、学者原话或理论名称
- 年龄比例只作为「一个很直觉的原因」，紧跟「往往不只是年龄」

## 仍然存在的不足

1. 人物是平面剪影骨架，近景动作（刷牙、回家、开窗）比较简单。
2. 部分「第一次」画格（买东西、摔倒）里孩子偏小，主要靠构图和光读出来。
3. 声音全部是代码合成的环境声，整体偏轻；正式发布前如果加 BGM，需要重新平衡音量。
4. 总长 120.0 s，在 108–120 s 的上限；如需缩到约 116 s，最容易删的是第 9 幕年龄比例里 20 岁那一档（约 1.4 s）和第 12 幕到站前的停顿（约 1.5 s）。
