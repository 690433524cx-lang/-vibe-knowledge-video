# 《时间错觉》分镜表

人文心理 / 认知科学动态短片 · 1920×1080 / 30fps / H.264 · 目标总长 **118 s**（设计时间轴）

- **MAIN_BEAT_T = 65.0 s**（暂定，仅用于结构；拿到指定 BGM 后用 `MAIN_BEAT_T=…` 整体平移高潮）
- 当前没有指定 BGM：**不加任何旋律型音乐**，只有环境声、关键音效和 T 处一个克制的低频冲击
- 普通字幕固定在下方安全区、水平居中、暖白；只有「第一次」「重复」「时间没有加速」「是重复，让它消失了」做中央排版
- 科学表达只讲「回顾时的时间感」，统一用「可能 / 往往 / 更容易 / 回头看时」；不引用具体实验数据、不编学者原话

## 节奏核对

- 前 20 秒：窗边 → 暑假碎片 → 日历/手机 → 一年翻完 → 三天通勤加速 → 地铁倒影，共 6 次明显场景变化
- 20–60 秒：共鸣（第一次）→ 解释（记忆密度）→ 共鸣（重复的五天）交替，没有连续 15 秒的理论
- 55–65 秒：累积（365 页）→ 突然清空 → T
- 71–98 秒：年龄比例（并明确说它不是唯一原因）→ 相册（回顾时的压缩）→ 空墙
- 98 秒以后：放慢，结尾回到开头的窗
