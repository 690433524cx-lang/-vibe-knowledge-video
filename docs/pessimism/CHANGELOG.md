## 1. 时长：为什么接近 120 s，而不是 105–115 s

这一版新增了解释风格 5 句、提前适应失去 3 句、提前痛一次 6 句，结尾从 3 句变成 10 句。合成两行后，字幕卡从 v2 的 34 张变成 45 张。字幕最短停留规则和这些台词加在一起，最少也要 119 秒左右。
我先压缩了所有没有字幕的画面（地图压缩 26%、三个生活例子从 16.5 s 压到 10.45 s、删掉蜡烛镜头、删掉人物页、删掉「最坏会发生什么？」那张纸和「真正有用的悲观」那段路线图），才控制在 120 s 以内（加上 1.3 s 片名后为 119.8 s）。
另外把 8 组连在一起读的短句合成上下两行（同一屏），**文字和顺序都没有改**：

| 两行合成一屏 |
|---|
| 很多悲观的人。/ 并不是在预测未来。 |
| 有时候。/ 我们提前想最坏。 |
| 只是因为觉得—— / 提前痛一次。 |
| 真正失去的时候。/ 就不会那么突然。 |

| 快乐会结束。/ 但它还没结束的时候—— |

如果要压到 115 s 以内，只能删台词，需要你决定删哪几句。
