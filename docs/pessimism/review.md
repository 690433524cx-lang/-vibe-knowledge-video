## 声音

第一幕：门外人声 + 三段笑声 → 1.94 s 门关闭（闷响 + 锁舌，与画面「咔」地顶住同一帧）→ 人声被门闷住、约 1 秒内消失 → 3.1 s 楼道灯继电器一声 → 只剩房间底噪；5.35 s 杯子放回桌上。
第二幕：椅子腿两三下轻磕；12.8 s 很远的鞭炮。第三幕：列车低频滚动 + 轨缝节奏。
整轨平均响度 −33 dB、峰值 −3.5 dB。**我没法试听**，人声和笑声是合成的，质感可能偏「电子」；如果听起来假，可以换成真实的环境录音（只需替换 `videos/pessimism/audio.js` 里的一个音效）。
