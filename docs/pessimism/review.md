## 对照提示词的检查

| 项目 | 结果 |

| 先快乐后悲观 | 聚会、年夜饭、旅行都先有快乐；空的画面只作为想象出现 |

| MAIN_BEAT_T 绑定 | T-1.2 / T-0.7 / T-0.3 / T-0.15 / T / 冲击音 / T 后字幕 / 「最坏」缩小都随 MAIN_BEAT_T 移动；T 那一帧画面中央只有「最坏」 |
| 学者照片 | 没有伪造人像：`assets/portraits/martin_seligman.*` 缺失时显示「PORTRAIT · 授权照片待导入」 |

## 已知不足

- 人物没有五官；关系那一幕的侧脸特写最近，平面感最明显。
- 工作那一幕的办公室仍然偏暗，工位排布看得不太清楚。
- 俯拍的「低头的人」是高度简化的头顶 + 肩膀 + 手臂。
- 地图上的手是简化的俯视手形。
- 声音全部是合成的，**我无法试听**；人声、笑声可能偏「电子」。
- Martin Seligman 照片仍需你提供（见 `sources.md`）。
