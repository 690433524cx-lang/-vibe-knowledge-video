## 四句核心句

| # | 句子 | 时间 | 画面 |
|---|---|---|---|
| 1 | 别人还在开心。/ 你已经开始舍不得了。 | 0–4.25 | 热闹的聚会，他安静下来 |
| 2 | 有些人不是不快乐。/ 是不敢快乐太久。 | 29.3–35.4 | 独立的蜡烛镜头 |
| 3 | 悲观不是等坏事发生。/ 它会提前活一遍。 | 40.6–46.7 | 回闪 → 想象出来的空房间 |
| 4 | 真正危险的。/ 不是你想到最坏。/ 是你开始把最坏—— / 当成唯一。 | 66.0–76.0 | 「最坏」 |

结尾：你可以知道快乐会结束。/ 但不用在快乐开始的时候—— / 就提前难过。

## 字幕系统

- 普通叙述与金句都固定在下方安全区（字幕中心约在画面底部往上 12%）、水平居中；只有「提前难过」「最坏」是画面里的锚词。
- 叙述 66 px、金句 74 px（比 v1 的 56 px 大约 18%–32%）；很淡的暗色柔底 + 轻阴影，任何背景上都读得清。
- 淡入 0.25 s、上移 6 px、淡出 0.22 s；不模糊、不缩放、不逐字、不飞入。前一句淡出后下一句才出现。
- 一句最多两行、每行不超过 15 字。

逐句检查（脚本按「4–8 字 ≥ 1.5 s、9–15 字 ≥ 2 s、16 字以上 ≥ 3 s」计算可见时间）：34 句全部合格，最短 1.7 s。

| 自检问题 | 结果 |
|---|---|
| 第一次看能不能完整读完 | 能：每句可见 1.7–3.4 s |
| 停留是否足够 | 是（见上） |
| 是否从左跳到右 | 否：全部同一位置 |
| 是否没读完就消失 | 否：不会被下一句提前截断（前一句淡出后下一句才出现） |
| 是否多个字幕同时抢注意力 | 否：同一时间只有一句；画面里的手写念头只出现在没有字幕或字幕很短的地方 |
| 是否有太小的字幕 | 否 |
| 是否压在复杂背景上看不清 | 暗色柔底 + 阴影保证可读 |
