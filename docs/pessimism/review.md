## 这一版改了什么

第一版把悲观拍成了「孤独、空、暗」。这一版的情绪逻辑是：**快乐正在发生的时候，他已经提前看见了它结束的样子**。

| 反馈 | 处理 |
|---|---|
| 片头要有「悲观主义」 | 0–1.5 s 片名压在热闹的聚会上，一秒多就退开；1.35 s 接「你是不是也这样？」 |
| 聚会必须先热闹 | 门口穿外套、站着聊天大笑、沙发上碰杯、扶手上喝东西、弯腰拿零食、前景有人走过——连他共 7 人，各自在动 |
| 「你已经在想它什么时候结束」出现时聚会还没散 | 3.95 s 出现时，其他人仍在聊天；只有他安静下来，镜头慢慢靠近他 |
| 空房间只能是想象 | 5.2–6.9 s 脑内的未来：人一下子消失、门关上、灯串灭、光变冷、桌上多出残杯；人声被抽空。6.9 s 人都回来了 |
| 春节先热闹 | 一家八口 + 跑过去的小孩，夹菜、举杯、碰杯、给他夹菜、聊天、笑，菜冒热气，窗外放鞭炮 |
| 热闹与散场用同一个镜位 | 10.3 s 之后机位几乎不动；12.6 起人一个一个淡出，鱼变成鱼骨、热气散去，最后只剩空椅子 |
| 每个场景有自己的视觉身份 | 聚会：暖褐 + 钨丝灯串 + 窗外城市；春节：深红桌布 + 红灯笼 + 暖黄吊灯 + 墨绿墙裙；旅行：冷蓝灰 + 黑 + 高速后退的灯 |
| 前 / 中 / 后景 | 聚会：失焦的酒杯、走过镜头的人 / 人群 / 窗外；春节：失焦的酒杯、前排背影和椅背 / 一家人 / 窗花与灯笼 |
| 旅行先期待 | 他朝窗户前倾、仰头看窗外；18.0 手机亮起 DAY 1，先停；19.5 才低头，20.6 之后才是 RETURN |

## 已知不足

- 人物没有五官，正面角度略像人偶；手是简化的椭圆。
- 小孩跑过时被后排的人挡住大半，不太显眼。
- 声音全部是合成的（人声、笑声、碰杯），**我无法试听**；如果听起来假，可以换成真实环境录音，只需改 `videos/pessimism/audio.js`。
