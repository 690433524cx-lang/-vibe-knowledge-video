## 音乐与时间轴

- 背景音乐计划使用《千年之后》。**当前项目里没有这首歌的音频**，所以本表**没有**分析任何 BPM、波形、重拍或乐句，以下「音乐状态」只是之前约定的情绪结构：
  克制 → 逐渐积累 → 情绪上升 → 明显换气 → **核心重拍** → 视觉高潮 → 情绪回落 → 知识解释 → 逐渐平静 → 结尾留白。
- 核心重拍参数 **MAIN_BEAT_T**，设计时间暂放在 **66.5 s**（要求的 64–75 s 区间内）。
- 所有场景、字幕、音效按「设计时间」编写。改 T 只需：
  `MAIN_BEAT_T=71.2 node src/render.js --video pessimism ...`
  高潮前收暗、T-1.2 / T-0.7 / T-0.3 / T-0.15 的词语动作、「最坏」落下、低频冲击、高潮后字幕，全部自动跟着 T 走（T±2 s 内 1:1 刚性，之前按比例伸缩，之后整体平移，也可用 `END` / `ANCHORS` 对齐乐句）。
- 前期样片**不放任何 BGM**，只有环境音和少量音效。

## 统一视觉

- **画面管线**沿用上一期第二版（`LOOK: 'v2'`）：非纯黑暗部、局部光源、纸张与胶片材质、极轻的片门晃动与焦点呼吸。
- **空间**：每个生活场景都是一个有透视的房间 / 车厢 / 走廊：墙、地面、家具、窗外的城市，前景有失焦遮挡物。
- **人物**：同一个成年人，简化但比例真实；侧影、背影、手。没有五官细节，不卡通、不 Q 版。只被场景里的光照到一侧，轮廓有暖色或冷色的边缘光。
- **灯光**就是叙事：聚会只剩一盏吊灯；春节红灯笼还亮着；深夜只有手机屏幕；面试门缝里是冷白光；人物页一侧亮一侧暗；道路远处亮、近处暗。
- **色彩**：炭黑、暖黑、烟灰、深褐、深蓝灰、低饱和墨绿；暗红只给「提前难过」「最坏」、红灯笼和红铅笔；高光为米白 / 暖灰白 / 钨丝灯黄。
- **字幕三级**：一级（钩子 / 金句，74 px，左下或居中）、二级（普通叙述 56 px，下方安全区）、三级（脑内声音 / 注释，44 px，贴着画面里的物体）。
- **字体**沿用账号体系：正文思源宋体（常规 / 600）；锚词「提前难过」「最坏」用马善政毛笔楷压成旧印刷质感；英文人名 / 术语 EB Garamond；手写念头龙藏体。
- **运动重量**：门重（临界阻尼、起步慢）；纸轻（有回弹）；手机稳（几乎不晃）；人物慢（呼吸、低头）；聊天气泡快（弹出带一点过冲）；「最坏」极重（落下 0.1 s，几乎不回弹，只有一次震动）。
