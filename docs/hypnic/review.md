## 对 0–20 s 的三处轻微优化（结构未改）

1. 下坠距离 145 → 165 px（约 15% 画面高度），坠落瞬间人体闪亮再强一点（0.95 → 1.0，持续略长）；「踩空」保持暖金 + 5 px 下沉；人体仍只抽一次，没有加任何特效
2. 从约 10 s 起中文节点 / 阶段名称统一放大约 15%：时间轴 37 → 43 px，三段状态轴 38 → 44 px，四个系统 35 → 40 px；20 s 之后的节点中文都在 40–46 px。英文仍为 15–18 px
3. 背景、金线、米白、线稿完全不变

## 自检

| 检查项 | 结果 |
|---|---|
| 黑底 | 31 张关键帧中亮度 < 40 的像素占 92.7–99.2% |
| 金色 / 暗红 | 金色只给节点、路径、关键词、数据曲线；暗红只出现在 J 段右路（四个小点 + 一个节点外圈） |
| 知识结构变化间隔 | 每 1–4 s 一次（节点、连线、曲线、波动、错位、镜头推进 / 收拢）；最长较静的段落是 49.5–51.8（"？"呼吸、50.3 连线亮一次）和 73–75.5（< 1 SEC 已缩小，字幕在读） |
| 必须出现的结构 | 清醒→睡眠状态轴（0–20 / 75–79 / 106–112）、神经信号路径（G 段）、完整思维导图（H 段）、真实 vs 感知曲线（F 段）、就医边界（J 段） |
| 字幕 | 全部固定底部居中 64 px；两行字幕的上一行在 y ≈ 885，已检查不压到画面元素。只有「踩空」（F 段中央 / 开场字幕内）和「入睡抽动」（标题 / 结尾 / 总图终点）脱离字幕体系。阅读时长全部达标，唯一例外是开场「为什么快睡着时——」1.4 s（v0.2 已确认） |
