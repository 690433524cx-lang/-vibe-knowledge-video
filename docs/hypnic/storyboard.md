## 科学依据与措辞

- 入睡抽动（sleep starts / hypnic jerks）在睡眠障碍国际分类（ICSD-3）中归入"孤立症状与正常变异"：发生在清醒到睡眠的过渡阶段，短暂、不自主的肌肉抽动，常伴下坠感、视觉闪光或惊醒感，大多数人一生中都经历过
- 机制尚未被单一理论完全确定。片中只说"一个常见解释认为 / 可能 / 被认为与……有关"
- 常被提到的加重因素：咖啡因与刺激物、睡眠不足、疲劳、精神压力 / 焦虑、睡前剧烈运动
- 就医边界：非常频繁、严重影响睡眠、白天也出现异常抽动、伴随其他神经症状 → 建议咨询医生。片中不做诊断
