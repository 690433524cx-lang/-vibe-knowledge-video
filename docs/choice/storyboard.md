# 《你是不是也有选择困难？》分镜表

## 音乐与时间轴

- 《千年之后》音频**尚未提供**：本表**没有**分析任何真实波形、BPM 或重拍。
- 主重拍参数 **MAIN_BEAT_T**（代码里也叫 T），暂定 **50.0 s**，只用于当前结构。
- 第二个小重拍 **T2** 暂放在「你是在逃避选错。」（设计时间 80.6 s），冲击明显弱于 T。拿到音乐后同样对齐到真实的小重拍。
- 所有场景按「设计时间」编写。渲染时：T±2 s 内 1:1 刚性；T 之前按比例伸缩；T 之后整体平移，也可用 END / ANCHORS 对齐乐句。
- 换 T 只需：`MAIN_BEAT_T=52.37 node src/render.js --video choice ...`，高潮前收暗、静止、「选对」、冲击音和之后的字幕全部自动跟随。

## 视觉第二版（本次升级）

全片改用第二版画面管线（`LOOK: 'v2'`），上一期《舍不得》不受影响：

- **暗部**：不再是纯黑。炭黑 / 暖黑 / 深褐 / 烟灰 / 橄榄灰的层次，暗处保留极淡的墙面肌理；最暗也停在暖炭黑。
- **光**：每个镜头都有明确的局部光源——门缝、手机屏幕、台灯、路灯、人物侧光；场景之间有极轻的冷暖差。
- **材质**：纸有纤维、厚度、磨损的毛边、受光不均、折痕和两层投影；字有墨色不均；肖像有银盐颗粒。
- **摄影**：极轻的片门晃动、焦点呼吸、曝光起伏、边缘光学柔化、粗细两层胶片颗粒；局部使用前景失焦与焦点转移。
- **运动**：阻尼弹簧代替 ease-in-out。门重（临界阻尼、起步慢）、纸轻（有回弹）、吊牌按阻尼摆停下、菜单按「甩动 + 摩擦」滚动、人物档案很慢、「选对」压下时只有极小的回弹。
- **排版**：正文改为常规字重、放松字距，位置随构图变化（多在左下留白，人物档案在侧栏）；英文人名和术语用 EB Garamond；关键词不频繁放大。
- **构图**：大量非对称和负空间。门偏右、问题落在左下；手机偏右；人物肖像只占一侧约 35% 并被画面边缘裁切。
- **前后变化**：前半段越来越满（门 → 菜单 → 吊牌 → 走廊 → 字墙），T 点只剩「选对」，后半段越来越空（选项 → 三张纸条 → 一页笔记 → 一扇门）。
