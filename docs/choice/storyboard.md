# 《你是不是也有选择困难？》分镜表

## 音乐与时间轴

- 《千年之后》音频**尚未提供**：本表**没有**分析任何真实波形、BPM 或重拍。
- 主重拍参数 **MAIN_BEAT_T**（代码里也叫 T），暂定 **50.0 s**，只用于当前结构。
- 第二个小重拍 **T2** 暂放在「你是在逃避选错。」（设计时间 80.6 s），冲击明显弱于 T。拿到音乐后同样对齐到真实的小重拍。
- 所有场景按「设计时间」编写。渲染时：T±2 s 内 1:1 刚性；T 之前按比例伸缩；T 之后整体平移，也可用 END / ANCHORS 对齐乐句。
- 换 T 只需：`MAIN_BEAT_T=52.37 node src/render.js --video choice ...`，高潮前收暗、静止、「选对」、冲击音和之后的字幕全部自动跟随。

## 时长说明（需要你决定）

按完整文案、手机上能读完的速度（短句约 1.0–1.3 s，长句约 1.5–2 s）排下来，全片设计时长约 **114 s**，比 85～95 s 的目标长约 20 s。原因是 T 前已有约 50 s，而 T 之后的知识点、两位学者、方法和结尾共约 64 s 的字幕。

如果要回到约 92 s，我建议的删减方案（每项约省下的时间）：

| 删减 | 省下 |
|---|---|
| 第四幕「城市」与「人生路线」合并为一次变化（车票直接变成两条路） | ~4 s |
| 第六幕两个术语之间少一句，「更多选择 / 本该是更多自由」合成一屏 | ~3 s |
| 第十幕（不断比较 / 搜索 / 拖延）压成一个 3 s 蒙太奇 | ~3 s |
| 第八幕「B / C / D」只做画面里的手写浮现，不再配字幕 | ~2 s |
| 第十一幕「20→10→5→3」与 Simon 档案卡重叠进行 | ~3 s |
| 第十二幕三条件卡少一句过渡字幕（「换一个问题」） | ~2 s |
| 第十三幕与结尾合并：门熄灭的过程中直接进结尾问题 | ~5 s |

前 20 秒不受影响。下表是完整版（114 s）。
