## 时间轴如何参数化

代码里所有场景都按「设计时间」编写（设计 T = 50）。渲染时：

| 区段 | 规则 |
|---|---|
| 0 → T-2.0 | 按比例伸缩（T 变大，前半段整体放慢；T 变小，整体加快） |
| T-2.0 → T+2.0 | **刚性**，1:1 不伸缩：T-1.0 / T-0.6 / T-0.5 / T-0.15 / T / T+0.5 / T+1.0 都是精确偏移 |
| T+2.0 → 片尾 | 默认整体平移；也可单独指定 END 让后半段伸缩到音乐结尾 |

拿到《千年之后》后只需：

```bash
T=52.37 node src/render.js --music assets/music/千年之后.mp3 --out output/final.mp4
# 后半段要对齐到某个乐句结尾：
T=52.37 END=104.8 node src/render.js ...
# 中间还要对齐更多乐句：
ANCHORS='[{"design":28,"real":28.9}]' T=52.37 node src/render.js ...
```

## 视觉基调（第二版）

深夜昏暗档案室：黑棕色桌面，只有主体被一束很弱的暖光照亮，四周压暗。电影票、号码牌、照片都是黑暗中被照亮的「生活证据」。字幕为浅米白 / 暖灰白，暗红只用于锚词、关键划线、印章和错误决策提示。

下表时间码为**设计时间**（T = 50）。T 窗口前后用 `T±x` 标注，其余时间会随 T 自动移动。

全片设计时长约 **108 s**。按需求把内容完整铺开，比 90～100 秒目标多出约 8 秒；拿到音乐后按乐句收束。如果需要硬压回 100 秒，优先压缩第八幕和第六幕的字幕间隔。
